## Project profile

- **Tier:** B (shared non-critical, no SLA)
- **Type:** 2 — Go CLI (protoc plugin binary)
- **Module:** `github.com/intrinsec/protoc-gen-checker`
- **Purpose:** Protoc plugin enforcing validation rules from `protoc-gen-validate`.
  Reports messages/fields with missing validation or validation disabled without a
  documented reason. Used by other Intrinsec services in their proto code-generation
  pipelines.
- **Go toolchain:** latest stable Go (currently `1.26.x`). Bump alongside upstream.

## Language

- Go only. No mixed-language tooling expected.
- Format: `gofmt` enforced; CI fails on diff.
- Build: `make build` (produces `bin/protoc-gen-checker`).
- Install: `make install` (`go install` into `$GOBIN`).
- Generated code: `checker/checker.pb.go` is generated from `checker/checker.proto`;
  do **not** hand-edit. Regenerate via `make` (depends on local `protoc-gen-go`).
